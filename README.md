# NanoScreen-AI Tumor Delivery Prioritization

## Project Title

Artificial intelligence-assisted prioritization of nanoparticle formulations for efficient tumor delivery

## Overview

This repository is prepared as the paper analysis-code and supplementary-material package for a screening-oriented machine-learning framework that prioritizes nanoparticle formulations with high predicted tumor delivery efficiency. The workflow includes dataset curation, high-delivery label construction, model optimization, out-of-fold and independent test-set evaluation, SHAP-based interpretation, virtual formulation screening, cancer-type-specific candidate screening, and local working-range summarization.

Model-prioritized candidates are computational outputs intended to guide future experimental validation. They are not experimentally validated optimal formulations.

The updated virtual-screening output was generated from 50,000 virtual nanoparticle candidates using chemistry-aware categorical feasibility filtering, real-database Type-MAT-Shape combination constraints, numeric out-of-distribution filtering, CatBoost high-delivery probability ranking, and top-candidate prioritization. The updated scored library contains 46,157 final candidates and exports the top 200 candidates.

Public Scripts

The scripts/ folder contains cleaned public code records and documentation files curated from the finalized analysis workflow.

main_analysis_final.py is the manually organized final public analysis code exported from the finalized Jupyter workflow. It preserves the main analysis workflow, including preprocessing, group-aware splitting, label construction, model training and evaluation, OOF-based model selection, SHAP analysis, virtual candidate screening, cancer-type-specific screening, and local working-range estimation.
figure_generation_cleaned.py is a cleaned public code record exported from the figure-generation notebook. It currently preserves code for selected data-driven performance-panel generation, especially Figure 4-related performance panels.

SHAP plotting and SHAP export logic are preserved mainly in main_analysis_final.py rather than figure_generation_cleaned.py.

Figure 1 was prepared separately as a schematic workflow figure and is not generated by the Python scripts. figure_generation_cleaned.py should not be interpreted as reproducing all final manuscript figures.

The cleaned scripts use repository-relative configuration variables and may require manual review of dependencies, input files, runtime requirements, and execution order before full re-execution in a different environment.

Running the cleaned scripts may train models, recompute outputs, or regenerate figures. They were not executed during repository preparation.

Supplementary Materials

The Supplementary materials/ folder contains the final supplementary materials prepared for the manuscript:

Supplementary Material A.docx: Word file containing Tables S1–S9 and supplementary data/code availability information.
Supplementary Material B.xlsx: Full analytical dataset, data partitioning, high-delivery labels, endpoint definition, threshold sensitivity analysis, variable dictionary, variable ranges, and categorical levels.
Supplementary Material C.xlsx: Model-evaluation outputs, cross-validation results, out-of-fold predictions, independent test-set predictions, model reports, optimized hyperparameters, and ranking-oriented metrics.
Supplementary Material D.xlsx: Virtual formulation screening outputs, scored candidates, top-ranked candidates, cancer-type-specific candidates, and local working-range estimation outputs.

The final supplementary materials are provided directly in the Supplementary materials/ folder.

The repository does not retain supplementary-material generation scripts.

Data Source

The analytical dataset and data dictionary used for this study are provided in Supplementary Material B.xlsx.

The file contains the cleaned analytical dataset, training and test split, high-delivery labels, endpoint definition, threshold sensitivity analysis, variable dictionary, variable ranges, and categorical levels.
